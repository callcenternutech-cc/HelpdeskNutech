CCIT Helpdesk UI Reference V6

This version is a presentation-focused implementation based on the supplied blue Helpdesk mobile mockup.

Implemented:
- Dashboard: blue header, 2x2 KPI cards, filters, charts, latest tickets.
- Bottom navigation with center + Create Ticket action.
- Ticket page: mobile quick status chips and compact card presentation through existing components.
- Ticket detail: existing data/actions retained; styling is aligned with the reference visual language.
- Create Ticket: mobile-friendly form and separate camera / file selection actions.
- User / Master Data: card surfaces and spacing aligned with the reference.
- Settings: light/dark theme retained.
- Android-specific camera compression and Back behavior are retained from the current source.

The ZIP intentionally excludes .env files, node_modules, Gradle build caches, and local.properties.
Set your production API variables in the project before building.
