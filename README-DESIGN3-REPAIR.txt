CCIT Helpdesk — Design 3 Integrated Repair

This package restores the complete stable v6 src tree and integrates only the Design 3 ticket-management changes.
It intentionally keeps the full index.css from v6 and appends the Design 3 CSS, instead of replacing index.css with the incomplete patch CSS.

Replace only the contents of your project src folder with this package:
D:\project\helpdesk-nutech-android\src

Native Android files, .env, and android/ are intentionally not included.
